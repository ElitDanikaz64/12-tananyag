## Tanároknak: 
A repo-t Visual Studio-ban C# projektként is használom órán, így a külömböző feladatok megoldásai külömböző mappákban vannak.
Le lehet futtatni őket könnyedén (Main() metódusokat) a runtime alatt kilistázott feladatnevekből. 
Megadod a feladat nevét a listából és már le is futott annak a Main-je.

Parancsok:
- list : kilistázza újra az elérhető feladatokat
- exit : szimplán kilép a programból.
